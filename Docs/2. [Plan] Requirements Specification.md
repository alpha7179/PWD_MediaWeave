# MediaWeave - 최종 제품 명세서 (As-Built Specification)

## 1. 프로젝트 개요 (Introduction)

### 1.1 서비스 비전 (Vision Statement)

> "우리의 이야기를 한곳에, 디미를 잇다."

아주대학교 디지털미디어학과 재학생을 위한 **통합 학습 관리 및 포트폴리오 플랫폼**. React Flow 기반 시각적 커리큘럼 로드맵, 프로젝트 갤러리, 팀 빌딩, 실시간 채팅을 통한 학과 커뮤니티 허브 역할 수행.

### 1.2 구현 완료된 핵심 기능

**✅ 완전 구현 완료:**

1. **시각적 커리큘럼 시스템**: React Flow 기반 트랙별 로드맵 + 드래그앤드롭 8학기 플래너
2. **프로젝트 포트폴리오**: 갤러리, 좋아요/댓글, 조회수 추적, 개인 프로필 연동
3. **팀 빌딩 플랫폼**: 모집 게시판, 지원 시스템, 실시간 채팅 연동
4. **성적표 OCR**: Tesseract.js 기반 자동 성적 인식 및 커리큘럼 동기화
5. **실시간 소통**: 팀/프로젝트별 메시징, 알림 시스템
6. **관리자 대시보드**: 사용자/데이터 관리, 통계 대시보드

## 2. 사용자 정의 및 실제 사용 패턴 (User Definition & Usage Patterns)

실제 구현된 시스템에서 확인된 사용자 역할과 권한 체계.

### 👥 사용자 역할 (User Roles)

**구현된 역할 체계 (User.role ENUM):**
- **STUDENT** (기본값): 일반 재학생, 모든 기본 기능 이용 가능
- **PROFESSOR**: 교수진, 프로젝트 평가 및 관리 권한
- **ADMIN**: 시스템 관리자, 전체 데이터 관리 권한

### 👤 Primary User: 재학생 (STUDENT)

**실제 구현된 기능 접근 권한:**
- ✅ 커리큘럼 로드맵 조회 (`/curriculum/roadmap`)
- ✅ 개인 학습 계획 수립 (`/curriculum/planner`)
- ✅ 프로젝트 CRUD 및 갤러리 (`/community/projects`, `/profile/projects`)
- ✅ 팀 빌딩 참여 (`/community/team-building`)
- ✅ 실시간 채팅 (`/profile/chat`)
- ✅ 성적표 업로드/OCR (`/profile/transcript`)
- ✅ 개인 포트폴리오 (`/profile`)

### 👨‍🏫 Secondary User: 관리자 (ADMIN)

**실제 구현된 관리 기능:**
- ✅ 사용자 관리 (`/admin`)
- ✅ 프로젝트 승인/거부
- ✅ 시스템 통계 대시보드
- ✅ 데이터 백업/복원

## 3. 구현된 기능 명세 (Implemented Features)

### 3.1 React Flow 기반 트랙 로드맵 (`/curriculum/roadmap`)

**✅ 구현 완료된 기능:**

#### 기술 스택
- **Frontend**: React Flow 11.11.4, Tailwind CSS 3.4.3
- **Backend**: Express.js + Sequelize ORM
- **Database**: Course, Track, StudentCurriculum 모델

#### 실제 구현된 입출력
- **입력**: 트랙 선택 (5개 트랙 지원), 과목 노드 클릭
- **처리**: Course-Track N:M 관계 기반 필터링, React Flow 자동 레이아웃
- **출력**: 인터랙티브 노드 그래프, 과목 상세 모달, 선수과목 관계 시각화

#### 실제 데이터 구조
```javascript
// Course 모델 (실제 구현)
{
  course_id: INTEGER,
  code: STRING, // 'CSE200'
  name_ko: STRING,
  name_en: STRING,
  credit: INTEGER,
  year: INTEGER, // 1-4
  semester: INTEGER, // 1-2
  credit_type: ENUM('REQUIRED', 'MAJOR', 'ELECTIVE', 'GENERAL'),
  prerequisites: TEXT // JSON 형태
}
```

### 3.2 드래그앤드롭 커리큘럼 플래너 (`/curriculum/planner`)

**✅ 구현 완료된 기능:**

#### 기술 스택
- **Frontend**: @dnd-kit/core 6.3.1, @dnd-kit/sortable 10.0.0
- **OCR**: Tesseract.js 7.0.0 (성적표 자동 인식)
- **Backend**: `/api/v1/my-plan`, `/api/v1/sync-plan` 엔드포인트

#### 실제 API 엔드포인트
```javascript
// 실제 구현된 라우트 (plannerRoutes.js)
GET    /api/v1/my-plan              // 개인 커리큘럼 조회
POST   /api/v1/my-plan              // 과목 배치 저장
POST   /api/v1/sync-plan            // 성적표 동기화
DELETE /api/v1/my-plan/:course_id   // 과목 제거
GET    /api/v1/graduation-status    // 졸업 요건 확인
```

#### 구현된 기능
- ✅ 8학기 그리드 레이아웃 (드래그앤드롭)
- ✅ 성적표 이미지 OCR 자동 인식
- ✅ 학기별 학점 실시간 계산
- ✅ 선수과목 유효성 검사
- ✅ 자동 저장 (Zustand 상태 관리)

### 3.3 프로젝트 갤러리 & 포트폴리오 (`/community/projects`)

**✅ 구현 완료된 기능:**

## 4. 실제 구현된 기술 스택 (Implemented Tech Stack)

### 4.1 Frontend Architecture

#### 핵심 프레임워크
- **React 18.2.0** + **Vite 5.2.0** (빌드 도구)
- **React Router DOM 7.10.1** (라우팅)
- **Zustand 5.0.9** (상태 관리)
- **TanStack React Query 5.90.12** (서버 상태 관리)
- **Axios 1.13.2** (HTTP 클라이언트)

#### UI/UX 라이브러리
- **Tailwind CSS 3.4.3** (스타일링)
- **Lucide React 0.556.0** (아이콘)
- **React Flow 11.11.4** (커리큘럼 시각화)
- **@dnd-kit/core 6.3.1** (드래그앤드롭)
- **React Hook Form 7.68.0** + **Zod 4.1.13** (폼 관리)

#### 특수 기능 라이브러리
- **Tesseract.js 7.0.0** (OCR 성적표 인식)
- **PapaParse 5.5.3** (CSV 파싱)

### 4.2 Backend Architecture

#### 핵심 프레임워크
- **Node.js** + **Express.js 5.2.1**
- **Sequelize 6.37.7** (ORM)
- **SQLite3 5.1.7** (개발용 DB) + **PostgreSQL 8.16.3** (운영용)

#### 인증 및 보안
- **JWT (jsonwebtoken 9.0.3)** (토큰 기반 인증)
- **Bcrypt 6.0.0** (비밀번호 암호화)
- **CORS 2.8.5** (교차 출처 리소스 공유)

#### 파일 처리
- **Multer 2.0.2** (파일 업로드)
- **CSV-Parser 3.2.0** (성적표 데이터 처리)

### 4.3 실제 구현된 데이터베이스 스키마

#### 핵심 엔티티 관계
```
User (사용자)
├── 1:N → Project (프로젝트)
├── 1:N → TeamPost (팀 모집)
├── 1:N → TeamApplication (팀 지원)
├── 1:N → Message (메시지)
├── N:M → Course (수강 이력 - StudentCurriculum)
└── N:M → Project (좋아요 - Like)

Course (교과목)
├── N:M → Track (트랙 관계)
├── 1:N → Project (과목별 프로젝트)
└── N:M → User (수강 이력)

Project (프로젝트)
├── 1:N → Comment (댓글)
├── 1:N → Like (좋아요)
├── 1:N → ProjectView (조회수)
└── 1:N → Message (프로젝트 채팅)
```

### 5.4 인증 시스템 (실제 구현)

#### JWT 기반 인증 플로우
```javascript
// 실제 구현된 인증 미들웨어 (auth.js)
const authenticateToken = (req, res, next) => {
  const authHeader = req.headers['authorization'];
  const token = authHeader && authHeader.split(' ')[1];
  
  if (!token) {
    return res.status(401).json({ message: 'Access token required' });
  }
  
  jwt.verify(token, process.env.JWT_SECRET, (err, user) => {
    if (err) return res.status(403).json({ message: 'Invalid token' });
    req.user = user;
    next();
  });
};
```

// User 모델의 실제 구현된 hooks
hooks: {

      const salt = await bcrypt.genSalt(10);
      user.password_hash = await bcrypt.hash(user.password_hash, salt);
    }
  }
}
