

# Media Weave - 최종 제품 설명서

- **프로젝트명:** 미디어 위브 (Media Weave)
- **슬로건:** 우리의 이야기를 한곳에, 디미를 잇다.
- **개발 완료일:** 2024년 12월
- **현재 상태:** 프로덕션 배포 완료

# 1. 제품 개요 (Product Overview)

## 1.1. 달성된 목표 (Achieved Goals)

아주대학교 디지털미디어학과 재학생을 위한 **통합 학습 관리 및 커뮤니티 플랫폼**으로서 다음 핵심 가치를 성공적으로 구현:

**✅ 구현 완료된 핵심 기능:**
- **커리큘럼 설계 지원**: 5개 트랙(DE, CD, GI, MD, VC) 기반 인터랙티브 로드맵 및 개인 맞춤형 수강 계획 도구
- **프로젝트 아카이빙**: 체계적인 학습 성과물 관리 및 공유 시스템
- **팀 빌딩 플랫폼**: 역량 기반 팀원 매칭 및 협업 지원
- **성적표 OCR 연동**: AIMS 성적표 이미지 자동 인식 및 커리큘럼 동기화
- **실시간 커뮤니케이션**: 1:1 채팅 및 팀 기반 메시징 시스템
- **통합 포트폴리오**: 개인 프로필 기반 학습 이력 및 성과 통합 관리

### 실제 달성 지표 (Achieved Metrics)

**개발 완료 기능 범위:**
- **사용자 관리**: 회원가입/로그인, 프로필 관리, 역할 기반 접근 제어 (ADMIN/PROFESSOR/STUDENT)
- **커리큘럼 관리**: 개인 수강 계획 생성/수정, 공개 커리큘럼 갤러리, 성적표 OCR 연동
- **프로젝트 갤러리**: 프로젝트 CRUD, 좋아요/댓글/조회수, 다중 필터링, 핀 기능
- **팀 빌딩**: 모집 게시판, 지원 시스템, 상태 관리 (모집중/완료)
- **커뮤니케이션**: 실시간 1:1 채팅, 팀 채팅, 알림 시스템
- **관리자 기능**: 사용자/프로젝트 관리, 통계 대시보드

**기술적 성과:**
- **프론트엔드**: React 18 + Vite 기반 SPA, TailwindCSS 디자인 시스템
- **백엔드**: Node.js + Express RESTful API, JWT 인증
- **데이터베이스**: PostgreSQL (관계형 데이터) + Sequelize ORM
- **파일 처리**: Multer 기반 이미지 업로드, Tesseract.js OCR 엔진
- **실시간 기능**: 메시징 시스템, 알림 시스템

## 1.2. 해결된 문제 (Solved Problems)

Media Weave는 디지털미디어학과 학생들이 직면했던 다음 핵심 문제들을 성공적으로 해결:

1. **✅ 커리큘럼 정보 투명성 확보** 
    - **해결책**: React Flow 기반 인터랙티브 트랙 로드맵으로 5개 트랙별 과목 연관성 시각화
    - **결과**: 학생들이 트랙별 학습 경로를 명확히 파악하고 체계적인 수강 계획 수립 가능
    
2. **✅ 개인 맞춤형 커리큘럼 설계 지원**
    - **해결책**: 드래그 앤 드롭 기반 4년 8학기 커리큘럼 플래너 + OCR 성적표 연동
    - **결과**: 기존 이수 과목 자동 인식 및 개인화된 수강 계획 효율적 관리
    
3. **✅ 학습 성과물 체계적 아카이빙**
    - **해결책**: 프로젝트 갤러리 시스템 (CRUD, 태그 기반 분류, 다중 필터링)
    - **결과**: 학과 내 우수 프로젝트 중앙 집중화 및 후배들의 학습 참고 자료 제공
    
4. **✅ 효율적인 팀 구성 프로세스**
    - **해결책**: 역량 기반 팀 빌딩 플랫폼 + 실시간 채팅 시스템
    - **결과**: 체계적인 팀원 모집 및 원활한 협업 커뮤니케이션 지원

5. **✅ 통합 포트폴리오 관리**
    - **해결책**: 개인 프로필 페이지 + 프로젝트/커리큘럼 연동 시스템
    - **결과**: 학습 이력과 성과물을 하나의 플랫폼에서 통합 관리 및 외부 공유 가능

## 1.4. 경쟁 분석 및 차별화 포인트

Media Weave는 기존 서비스들의 장점을 통합하여 **디지털미디어학과 특화 플랫폼**으로 차별화:

| 기존 서비스 | 차용된 핵심 기능 | Media Weave 구현 결과 |
| --- | --- | --- |
| **진로 로드맵 MIL** | 학과 커리큘럼 시각화 | `커리큘럼 > 트랙 로드맵` - React Flow 기반 인터랙티브 그래프 |
| **링크드인 (LinkedIn)** | 학습 이력 통합 관리 | `내 프로필` - 이수 과목, 프로젝트, 커리큘럼 통합 뷰 |
| **깃허브 (GitHub)** | 프로젝트 아카이빙 | `커뮤니티 > 프로젝트 갤러리` - 태그 기반 분류 및 검색 |
| **노션 (Notion)** | 유연한 계획 도구 | `커리큘럼 > 커리큘럼 플래너` - 드래그 앤 드롭 수강 계획 |
| **에브리타임** | 학생 커뮤니티 | `커뮤니티 > 팀 빌딩` - 역량 기반 팀원 매칭 |

### **실현된 차별화 포인트**

1. **학과 특화 통합 플랫폼**: 커리큘럼 설계부터 프로젝트 관리, 팀 빌딩까지 원스톱 서비스
2. **OCR 기반 자동화**: 성적표 이미지 인식을 통한 기존 이수 과목 자동 입력
3. **실시간 협업 지원**: 팀 빌딩과 연계된 채팅 시스템으로 즉시 소통 가능
4. **시각적 커리큘럼 관리**: React Flow 기반 인터랙티브 로드맵 + 드래그 앤 드롭 플래너
5. **포트폴리오 통합**: 학습 이력과 프로젝트 성과를 하나의 프로필에서 관리

# 2. 제품 기능 명세

## 2.1. 핵심 가치 (Core Value)

재학생의 **커리큘럼**(학습 과정)과 **프로젝트**(학습 성과) 유기적 연결(Weave)을 통한 성공적 **커리어**(미래 설계) 구축 지원 학과 특화 커뮤니티 플랫폼.

**실현된 핵심 가치:**

1. **✅ 투명성 (Clarity)**: React Flow 기반 트랙 로드맵으로 복잡한 커리큘럼 연관성 시각화 완료
2. **✅ 증명성 (Evidence)**: 개인 프로필에서 이수 과목-프로젝트 연계 포트폴리오 구축 완료  
3. **✅ 협력성 (Collaboration)**: 팀 빌딩 + 실시간 채팅으로 원활한 협업 지원 완료

## 2.2. 실제 구현된 사용자 플로우

    ├── /community/* (커뮤니티 관련)
    │   ├── /community/projects (프로젝트 갤러리)

## 2.3. 구현된 주요 기능

### 1. 랜딩 페이지 (/)

- **구현 상태**: ✅ 완료
- **주요 기능**: 서비스 소개, 로그인/회원가입 유도, 주요 기능 프리뷰
- **기술 구현**: React 컴포넌트, TailwindCSS 반응형 디자인

### 2. 대시보드 (/dashboard)

- **구현 상태**: ✅ 완료  
- **주요 기능**: 
  - 인기 프로젝트 상위 6개 표시 (조회수, 좋아요 기반)
  - 최신 팀 빌딩 게시글 표시
  - 개인 활동 요약 (내 프로젝트, 커리큘럼 현황)
- **기술 구현**: React Query 기반 데이터 페칭, 실시간 통계 연동

### 3. 커리큘럼 관리 (/curriculum/*)

#### 3.1 트랙 로드맵 (/curriculum/roadmap)
- **구현 상태**: ✅ 완료
- **주요 기능**:
  - React Flow 기반 인터랙티브 그래프 시각화
  - 5개 트랙(DE, CD, GI, MD, VC) 선택 탭 필터
  - 과목 노드 클릭 시 상세 정보 모달 (과목 개요, 선수과목, 관련 프로젝트)
  - 그래프 확대/축소/패닝 지원
- **기술 구현**: ReactFlow 11.11.4, 동적 노드 생성, 선수과목 관계 시각화

#### 3.2 커리큘럼 플래너 (/curriculum/planner)  
- **구현 상태**: ✅ 완료
- **주요 기능**:
  - 4년 8학기 그리드 UI (1-1 ~ 4-2)
  - 드래그 앤 드롭 과목 배치 (@dnd-kit 라이브러리)
  - 이수 완료/수강 중/수강 예정 상태 시각적 구분
  - 선수과목 위배 실시간 유효성 검사
  - 커리큘럼 저장/수정/삭제
- **기술 구현**: @dnd-kit/core, @dnd-kit/sortable, Zustand 상태 관리

#### 3.3 커리큘럼 갤러리 (/curriculum/gallery)
- **구현 상태**: ✅ 완료  
- **주요 기능**:
  - 공개 설정된 타 사용자 커리큘럼 조회
  - 트랙/학년별 필터링
  - 커리큘럼 복사 기능 (Copy to My Plan)
  - 카드형 갤러리 레이아웃
- **기술 구현**: 공개 커리큘럼 API, 복사 기능, 필터링 시스템

### 4. 커뮤니티 (/community/*)

#### 4.1 프로젝트 갤러리 (/community/projects)
- **구현 상태**: ✅ 완료

  - 프로젝트 CRUD (생성, 조회, 수정, 삭제)

  - 다중 필터링 (트랙, 프로젝트 타입, 기술 스택)
  - 정렬 (최신순, 인기순, 조회수순)
  - 프로젝트 핀 기능
- **기술 구현**: 파일 업로드, 좋아요/댓글 API, 다중 필터 시스템

#### 4.2 팀 빌딩 (/community/team-building)  
- **구현 상태**: ✅ 완료

  - 지원 시스템 (Apply to Team)
  - 모집 상태 관리 (모집 중/모집 완료)

  - 지원자 관리 (승인/거절)
- **기술 구현**: 게시판 시스템, 지원 관리 API, 상태 관리

#### 4.3 커리어 프로필 (/community/career)
- **구현 상태**: ✅ 완료 (목업 데이터 기반)
- **주요 기능**: 
  - 학과 내 학생들의 커리어 프로필 조회
  - 트랙별, 학년별 필터링
  - 프로젝트 포트폴리오 연동
- **기술 구현**: 프로필 데이터 연동, 필터링 시스템
