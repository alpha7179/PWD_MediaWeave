# Media Weave 중간발표 자료

## 📌 프로젝트 개요

### 프로젝트명
**Media Weave (미디어 위브)**

### 슬로건
**"우리의 이야기를 한곳에, 디미를 잇다"**

### 목표
아주대학교 디지털미디어학과 재학생의 5개 자율 트랙(GI, VC, CD, MD, DE) 커리큘럼 설계를 위한 정보 제공 및 프로젝트 공유 플랫폼

### 1. 미디어 커리큘럼
- **트랙 로드맵**: 5개 트랙별 과목 선수과목 관계 시각화
- **나만의 커리큘럼 짜기**: 4년 8학기 학습 계획 수립
- **공유된 커리큘럼**: 선배들의 검증된 커리큘럼 참고

### 2. 커뮤니티
- **프로젝트 갤러리**: 학생 프로젝트 아카이빙 및 공유
- **팀 빌딩**: 역량 기반 팀원 모집 시스템

### 3. 내 프로필
- 이수 과목 및 프로젝트 통합 관리
- 포트폴리오 페이지로 활용 가능

## 🚀 구현된 핵심 기술

### 1. React Flow 기반 로드맵 시각화
**기술적 도전:**
- 100개 이상의 과목 노드 렌더링
- 선수과목 관계 기반 엣지 생성
- 학년별 동적 레이아웃 계산
- 트랙별 필터링 및 포커스 기능

**해결 방법:**
```javascript
// 동적 레이아웃 알고리즘
1. 학년별 과목 그룹화
2. 학기별 최대 행 수 계산
3. 트랙별 X 좌표 오프셋 적용
4. 선수과목 관계 기반 Y 좌표 조정
5. 학년 박스 높이 자동 계산
```

### 2. CSV 데이터 파싱 및 캐싱
**기술적 도전:**
- 5개 CSV 파일 동시 로딩
- 관계형 데이터 조인 (과목-선수과목-트랙)
- 성능 최적화

**해결 방법:**
```javascript
// PapaParse + Promise.all
const loadCurriculumData = async () => {
  const [courses, prerequisites, tracks, courseTracks] = 
    await Promise.all([
      parseCsv('Course.csv'),
      parseCsv('Course_Prerequisites.csv'),
      parseCsv('Track.csv'),
      parseCsv('Course_Tracks.csv')
    ]);
  
  // 메모리 캐싱
  return { courses, prerequisites, tracks };
};
```

### 3. 드래그 앤 드롭 커리큘럼 플래너
**기술적 도전:**
- 8개 학기 그리드 간 드래그
- 과목 중복 방지
- 상태 관리

**해결 방법:**
```javascript
// @dnd-kit/core + @dnd-kit/sortable
- DndContext로 전역 드래그 컨텍스트 관리
- SortableContext로 각 학기 그리드 관리
- useSortable 훅으로 개별 과목 드래그 처리
```

### 4. 상태 관리 (Zustand)
**기술적 도전:**
- 인증 상태 전역 관리
- UI 상태 (모달, 토스트) 관리
- 로컬 스토리지 동기화

**해결 방법:**
```javascript
// Zustand 스토어
const useAuthStore = create((set) => ({
  user: null,
  token: localStorage.getItem('token'),
  login: (user, token) => {
    localStorage.setItem('token', token);
    set({ user, token });
  },
  logout: () => {
    localStorage.removeItem('token');
    set({ user: null, token: null });
  }
}));
```

## 📝 API 설계 (예정)

### 인증 API
```
POST /api/v1/auth/register    - 회원가입
POST /api/v1/auth/login       - 로그인
POST /api/v1/auth/refresh     - 토큰 갱신
POST /api/v1/auth/logout      - 로그아웃
```

### 트랙/과목 API
```
GET  /api/v1/tracks                    - 트랙 목록
GET  /api/v1/tracks/:id/roadmap        - 트랙 로드맵
GET  /api/v1/courses/:id               - 과목 상세
```

### 커리큘럼 API
```
POST   /api/v1/curriculums             - 커리큘럼 생성
GET    /api/v1/curriculums/my          - 내 커리큘럼 목록
GET    /api/v1/curriculums/public      - 공유된 커리큘럼
POST   /api/v1/curriculums/import-csv  - CSV 임포트
PATCH  /api/v1/curriculums/:id         - 커리큘럼 수정
DELETE /api/v1/curriculums/:id         - 커리큘럼 삭제
```

### 프로젝트 API
```
GET    /api/v1/projects                - 프로젝트 목록
GET    /api/v1/projects/:id            - 프로젝트 상세
POST   /api/v1/projects                - 프로젝트 생성
PATCH  /api/v1/projects/:id            - 프로젝트 수정
DELETE /api/v1/projects/:id            - 프로젝트 삭제
POST   /api/v1/projects/:id/like       - 좋아요
```

### 팀 빌딩 API
```
GET    /api/v1/team-building           - 모집 공고 목록
GET    /api/v1/team-building/:id       - 공고 상세
POST   /api/v1/team-building           - 공고 작성
PATCH  /api/v1/team-building/:id       - 공고 수정
DELETE /api/v1/team-building/:id       - 공고 삭제
```
