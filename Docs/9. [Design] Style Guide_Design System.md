## 2. 디자인 원칙 (Design Principles)

### 2.1. 핵심 가치

1. **미래지향적 디자인 (Futuristic Design)**
   - 글래스모피즘(Glassmorphism) 효과 적용
   - 네온 글로우(Glow) 효과로 사이버펑크 감성
   - 다크모드 우선 설계

2. **명확성 (Clarity)**
   - 복잡한 커리큘럼 정보의 직관적 시각화
   - 트랙별 색상 시스템으로 정보 구분

3. **일관성 (Consistency)**
   - 모든 페이지에서 동일한 패턴 사용
   - 컴포넌트 기반 설계

4. **접근성 (Accessibility)**
   - 다크모드/라이트모드 지원
   - 키보드 네비게이션 지원
   - 색상 대비 고려

5. **반응성 (Responsiveness)**
   - 모바일 우선 설계 (Mobile-First)
   - 데스크톱, 태블릿, 모바일 최적화

## 7. 컴포넌트 (Components) - 실제 구현

### 7.1. 버튼 (Button)

#### 7.1.1. 실제 구현된 버튼 컴포넌트

```jsx
// Button.jsx (실제 구현)
const Button = ({ 
  children, 
  variant = 'primary', 
  size = 'md', 
  className = '', 
  ...props 
}) => {
  const baseStyles = 'inline-flex items-center justify-center font-medium transition-all duration-200 rounded-lg focus:outline-none focus:ring-2 focus:ring-offset-2 focus:ring-offset-dark-bg disabled:opacity-50 disabled:cursor-not-allowed';
  
  const variants = {
    primary: 'bg-primary-600 hover:bg-primary-500 text-white shadow-glow hover:shadow-lg',
    secondary: 'bg-dark-card hover:bg-opacity-80 text-white border border-gray-700',
    accent: 'bg-accent hover:bg-opacity-90 text-white shadow-glow-accent',
    outline: 'border-2 border-primary-500 text-primary-400 hover:bg-primary-500/10',
    ghost: 'text-gray-600 dark:text-gray-400 hover:text-gray-900 dark:hover:text-white hover:bg-gray-100 dark:hover:bg-white/5'
  };

  const sizes = {
    sm: 'px-3 py-1.5 text-sm',
    md: 'px-5 py-2.5 text-base',
    lg: 'px-6 py-3 text-lg'
  };

  return (
    <button 
      className={`${baseStyles} ${variants[variant]} ${sizes[size]} ${className}`}
      {...props}
    >
      {children}
    </button>
  );
};
```

            Icon && "pl-11",
            error && "border-red-500 focus:border-red-500 focus:ring-red-500/50",
            className
          )}
          {...props}
        />
      </div>

      )}
    </div>
  );
});

## 11. 접근성 가이드라인 (Accessibility Guidelines)

### 11.1. 색상 대비 (Color Contrast)

#### WCAG 2.1 AA 기준 준수

**일반 텍스트 (16px 미만)**
- 최소 대비 비율: 4.5:1
- 예시: `#111827` (text-primary) on `#FFFFFF` (bg-primary) = 16.1:1 ✓

**큰 텍스트 (18px 이상 또는 14px Bold)**
- 최소 대비 비율: 3:1
- 예시: `#6B7280` (text-secondary) on `#FFFFFF` = 4.6:1 ✓

**UI 컴포넌트 및 그래픽 요소**
- 최소 대비 비율: 3:1
- 예시: 버튼 테두리, 입력 필드 테두리

#### 색상 대비 검증 테이블

| 전경색 | 배경색 | 대비 비율 | WCAG AA | WCAG AAA |
|--------|--------|----------|---------|----------|
| text-primary (#111827) | bg-primary (#FFFFFF) | 16.1:1 | ✓ | ✓ |
| text-secondary (#6B7280) | bg-primary (#FFFFFF) | 4.6:1 | ✓ | ✗ |
| primary-600 (#4F46E5) | bg-primary (#FFFFFF) | 7.3:1 | ✓ | ✓ |
| error-500 (#EF4444) | bg-primary (#FFFFFF) | 4.5:1 | ✓ | ✗ |
| success-700 (#047857) | success-50 (#ECFDF5) | 7.8:1 | ✓ | ✓ |

#### 색상만으로 정보 전달 금지

### 11.2. 키보드 네비게이션 (Keyboard Navigation)

#### Tab 순서 (Tab Order)

- 모든 인터랙티브 요소는 `Tab` 키로 접근 가능
- 논리적 순서로 포커스 이동 (좌→우, 상→하)
- `tabindex="0"`: 자연스러운 Tab 순서에 포함
- `tabindex="-1"`: Tab으로 접근 불가, JavaScript로만 포커스 가능
- `tabindex="1+"`: 사용 금지 (자연스러운 순서 방해)

#### Focus 상태 스타일

```css
/* 모든 포커스 가능 요소 */
*:focus-visible {
  outline: 2px solid var(--primary-500);
  outline-offset: 2px;
  border-radius: var(--border-radius-sm);
}

/* 버튼 포커스 */
.btn:focus-visible {
  outline: 2px solid var(--primary-500);
  outline-offset: 2px;
}

/* 입력 필드 포커스 */
.input:focus-visible {
  outline: none;
  border-color: var(--primary-500);
  box-shadow: 0 0 0 3px rgba(99, 102, 241, 0.1);
}

/* 링크 포커스 */
a:focus-visible {
  outline: 2px solid var(--primary-500);
  outline-offset: 2px;
  border-radius: var(--border-radius-sm);
}
```

#### 키보드 단축키

| 키 | 동작 |
|----|------|
| `Tab` | 다음 요소로 포커스 이동 |
| `Shift + Tab` | 이전 요소로 포커스 이동 |
| `Enter` | 버튼/링크 활성화 |
| `Space` | 버튼 활성화, 체크박스 토글 |
| `Esc` | 모달/드롭다운 닫기 |
| `Arrow Keys` | 드롭다운/메뉴 내 이동 |

## 11. 다크모드 (Dark Mode) - 실제 구현

### 11.1. 다크모드 설정

```javascript
// tailwind.config.js
darkMode: 'class',  // 클래스 기반 다크모드
```

### 11.2. 다크모드 토글 (실제 구현)

```jsx
// useUiStore.js - Zustand 스토어
const useUiStore = create((set) => ({
  darkMode: localStorage.getItem('darkMode') === 'true',
  toggleTheme: () => set((state) => {
    const newDarkMode = !state.darkMode;
    localStorage.setItem('darkMode', newDarkMode);
    if (newDarkMode) {
      document.documentElement.classList.add('dark');
    } else {
      document.documentElement.classList.remove('dark');
    }
    return { darkMode: newDarkMode };
  }),
}));
```

### 11.3. 다크모드 색상 시스템

```css
/* 라이트모드 */
.bg-gray-50 { background-color: #F9FAFB; }
.text-gray-900 { color: #111827; }

/* 다크모드 */
.dark\:bg-dark-bg { background-color: #0F172A; }
.dark\:text-dark-text { color: #F8FAFC; }
.dark\:glass { /* 글래스모피즘 효과 */ }
```

### 11.4. 다크모드 우선 설계

- 다크모드가 기본 디자인 방향
- 글래스모피즘 효과는 다크모드에서만 적용
- 라이트모드는 전통적인 화이트 배경 사용
