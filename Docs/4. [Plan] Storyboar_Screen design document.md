# Media Weave - 최종 제품 설명서
## 프로젝트 갤러리 & 상세 페이지 구현 현황

**구현된 핵심 기능:**

1. **프로젝트 갤러리:** 카드 기반 그리드 레이아웃으로 프로젝트 목록 표시, 트랙별 필터링, 검색 및 정렬 기능
2. **커리큘럼 연동:** 과목-프로젝트 연결, 트랙별 분류 시스템으로 학습 경로와 결과물 매핑
3. **커뮤니티 기능:** 좋아요, 조회수, 댓글 시스템을 통한 사용자 인터랙션
4. **반응형 디자인:** Tailwind CSS 기반 다크모드 지원, 모바일 최적화

## 1. 프로젝트 갤러리 메인 페이지 (구현 완료)

> 실제 구현된 프로젝트 갤러리는 카드 기반 그리드 레이아웃으로, 프로젝트 목록을 시각적으로 표시하며 다양한 필터링과 검색 기능을 제공합니다.

### [구현된 UI 구성요소]

1. **헤더 섹션**
    - **제목 및 설명:** "프로젝트 갤러리" 타이틀과 설명 텍스트
    - **프로젝트 등록 버튼:** 우측 상단에 Plus 아이콘과 함께 배치
    - **그라디언트 섀도우:** Primary 컬러 기반 그림자 효과 적용

2. **필터링 시스템**
    - **트랙 필터:** 전체, GI, VC, AI, CD, MD, DE 트랙별 필터링
    - **검색 바:** 프로젝트 제목, 태그, 작성자 통합 검색
    - **과목 선택:** 드롭다운으로 특정 과목 관련 프로젝트 필터링
    - **정렬 옵션:** 최신순, 오래된순, 인기순(좋아요 기준)

3. **통계 카드 섹션**
    - **총 프로젝트 수:** Layers 아이콘과 함께 표시
    - **사용된 기술 스택 수:** Code 아이콘, 중복 제거된 고유 기술 개수
    - **총 좋아요 수:** Heart 아이콘, 모든 프로젝트 좋아요 합계
    - **참여 학생 수:** Users 아이콘, 고유 사용자 수

4. **프로젝트 카드 그리드**
    - **레이아웃:** 반응형 그리드 (Desktop: 3열, Tablet: 2열, Mobile: 1열)
    - **카드 구성:**
        - 썸네일 이미지 (16:9 비율, 높이 192px)
        - 트랙 뱃지 (우측 상단, 트랙별 고유 색상)
        - 프로젝트 제목 (1줄 제한, 말줄임표 처리)
        - 설명 텍스트 (2줄 제한)
        - 기술 스택 태그 (최대 3개 표시, 초과 시 "+N" 표시)
        - 하단 메타 정보: 작성자 아바타, 이름, 조회수, 좋아요 수

### [인터랙션 및 상태 관리]

- **카드 호버 효과:** 
    - 1.01배 스케일 확대

    - 채워진/빈 하트 아이콘 토글
    - 실시간 카운트 증감
- **모달 시스템:**

## 2. 프로젝트 상세 모달 (구현 완료)

> 프로젝트 카드 클릭 시 열리는 모달로, 프로젝트의 상세 정보를 표시하며 사용자 인터랙션을 제공합니다.

### [구현된 UI 구성요소]

1. **모달 헤더**
    - **프로젝트 제목:** 모달 타이틀로 표시
    - **닫기 버튼:** 우측 상단 X 버튼

2. **프로젝트 정보 섹션**
    - **썸네일 이미지:** 대형 이미지 표시 (없을 경우 플레이스홀더)
    - **기본 정보:**
        - 프로젝트 제목 및 설명
        - 작성자 정보 (아바타, 이름)
        - 생성일, 조회수, 좋아요 수
    - **트랙 및 과목 정보:**
        - 연관 트랙 뱃지 표시
        - 관련 과목 정보 (있는 경우)
    - **기술 스택:**
        - 태그 형태로 모든 기술 스택 표시
        - 색상 구분 및 호버 효과

3. **인터랙션 버튼**
    - **좋아요 버튼:** 하트 아이콘, 실시간 토글
    - **수정/삭제 버튼:** 작성자인 경우에만 표시
    - **공유 기능:** (구현 예정)

## 3. 네비게이션 및 레이아웃 시스템 (구현 완료)

> 전체 애플리케이션의 네비게이션 구조와 레이아웃 시스템이 구현되어 있습니다.

### [사이드바 네비게이션]

1. **브랜드 로고**
    - **위치:** 사이드바 상단
    - **디자인:** "MEDIA WEAVE" 그라디언트 텍스트 (Blue → Purple → Pink)
    - **폰트:** April16thLife 커스텀 폰트 적용

2. **메뉴 구조**
    - **대시보드:** 홈 아이콘, 메인 대시보드 페이지
    - **커리큘럼:** 확장 가능한 서브메뉴
        - 커리큘럼 로드맵 (ReactFlow 기반 시각화)
        - 커리큘럼 플래너 (드래그앤드롭 학업 계획)
        - 커리큘럼 갤러리 (공유된 학업 계획)
    - **커뮤니티:** 확장 가능한 서브메뉴
        - 프로젝트 갤러리 (현재 페이지)
        - 팀 빌딩 (팀원 모집)
        - 프로필 공유 (커리어 프로필)
    - **나의 위브:** 확장 가능한 서브메뉴
        - 내 정보 (프로필 관리)
        - 성적 관리 (OCR 성적표 업로드)
        - 프로젝트 관리 (내 프로젝트 목록)
        - 커리큘럼 관리 (저장된 학업 계획)
        - 대화 관리 (채팅 기록)
    - **관리자:** 관리자 권한 사용자에게만 표시

3. **인터랙션 특징**
    - **자동 확장:** 현재 페이지가 속한 메뉴는 자동으로 확장
    - **애니메이션:** 서브메뉴 확장/축소 시 부드러운 애니메이션
    - **활성 상태:** 현재 페이지는 Primary 컬러로 강조
    - **호버 효과:** 메뉴 아이템 호버 시 배경색 변경

### [헤더 시스템]

1. **검색 바**
    - **위치:** 헤더 좌측, 최대 너비 제한
    - **기능:** 전역 검색 (프로젝트, 트랙, 학생)
    - **아이콘:** 돋보기 아이콘, 포커스 시 Primary 컬러 변경

2. **우측 액션 영역**
    - **알림 드롭다운:** 벨 아이콘, 실시간 알림 표시
    - **사용자 프로필 드롭다운:**
        - 아바타 (이니셜 기반 그라디언트 배경)
        - 사용자 이름 및 역할 표시
        - 드롭다운 메뉴: 프로필, 설정, 다크모드 토글, 로그아웃

3. **다크모드 지원**
    - **토글 스위치:** 헤더 드롭다운 내 위치
    - **전역 적용:** Tailwind CSS 다크모드 클래스 기반
    - **상태 저장:** 로컬 스토리지에 사용자 선호도 저장

**Media Weave 프로젝트 갤러리**는 기획 단계에서 구상했던 상세 페이지 중심의 구조에서 **모달 중심의 간소화된 구조**로 변경되어 구현되었습니다. 

### 주요 변경사항:
- **상세 페이지 → 상세 모달**: 별도 페이지 대신 모달로 프로젝트 정보 표시
- **미디어 슬라이더 → 단일 썸네일**: 복잡한 미디어 갤러리 대신 단일 썸네일 이미지
- **마크다운 에디터 → 간단한 텍스트**: 풍부한 콘텐츠 에디터 대신 기본 설명 필드
- **댓글 시스템**: 백엔드 구조는 존재하나 프론트엔드 미구현

### 성공적으로 구현된 핵심 기능:
- ✅ **프로젝트 갤러리**: 카드 기반 그리드 레이아웃
